# 花海剪贴板模块化边界

花海剪贴板采用适合单机小工具的轻量模块化，不引入微服务、Electron、前端框架或插件系统。

## 当前边界

- `HuahaiClipboard.Core`：数据模型、剪贴板历史、隐私过滤、设置、窗口策略和更新安全策略；不依赖 WinUI。
- `HuahaiClipboard.App`：WinUI 窗口、WebView 桥接、托盘、全局输入、开机启动和 Windows 集成。
- `Assets/Web/product-shell.html`：唯一批准的 UI 主壳，负责页面结构、设计令牌和功能编排；网页版与 EXE 共用。
- `Assets/Web/*.js`：按单一职责拆分保留策略、宿主缩放、玻璃透明度、面板拖动、快捷输入、交互合同标记和哈希路由。
- `installer`：安装位置、目录所有权、前置包、升级与回滚策略。
- `tests`：Core 单元测试、Web 行为测试、真实 WinUI/WebView 烟测和安装/更新门禁。

## 本阶段规则

- 已确认的液态玻璃视觉、狐狸图标、艺术字和动效只从 `product-shell.html` 派生，不建立第二套 UI。
- 新增纯规则优先进入 Core 或独立 Web 模块；Windows API 只留在 App/installer。
- 不为未来假设增加框架、依赖注入容器、插件系统或远程服务。
- 主壳只保留页面编排；当一段逻辑可独立测试且超过一个职责时再拆分。

## 后续非阻断项

- 更新状态控制器与记录列表渲染器若继续增长，再分别抽为模块。
- 托盘菜单若增加超过当前三个命令，再抽出可测试的菜单命令模型。

这些项目不阻断 v1.1.2；只有实际新增功能触及对应区域时才执行，避免把小工具过度工程化。
