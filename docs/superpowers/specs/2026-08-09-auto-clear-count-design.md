# 按复制条数自动清除：交互原型设计

## 目标

为“花海剪贴板”增加按历史记录数量自动清除的设置，让用户限制普通历史记录数量，避免剪贴板历史无限增长。

## 已确认规则

- 用户可开启或关闭“按条数自动清除”。
- 用户设置一个最大普通历史条数。
- 达到上限后，自动从最早的普通记录开始清除。
- 收藏和置顶记录始终保留，不计入可清除普通记录的淘汰顺序。
- 功能只影响历史记录，不删除图片缓存、设置、收藏或置顶数据。
- 设置保存到本机，不联网、不上传记录内容。

## 原型交互

原型在“设置 → 本机存储”中增加一个独立卡片：

1. “按条数自动清除”开关。
2. 开启后显示条数输入控件，默认 100 条，允许用户输入正整数。
3. 显示当前状态，例如“普通记录 87 / 100 条”。
4. 显示规则提示：“达到上限后清除最早的普通记录；收藏和置顶始终保留”。
5. 提供“模拟达到上限”按钮，用合成数据演示自动清除结果。
6. 模拟结果显示清除数量、保留数量和被保护的收藏/置顶数量，可恢复原型数据。

## 状态

- 关闭：仅展示开关，不执行数量限制。
- 开启且未达上限：显示绿色状态和剩余可用条数。
- 达到上限：显示提醒色，并提供将被清除的普通记录数量。
- 输入无效：禁止保存，提示“请输入 1–10000 之间的整数”。
- 模拟完成：显示结果卡片，不修改正式应用数据。

## 视觉约束

- 沿用当前 WebView 液态玻璃材质、五套主题、艺术字和樱花背景层。
- 新卡片只添加到本机存储页，不改变主面板布局。
- 所有按钮必须可交互；原型中的模拟操作明确标注为“演示，不会修改正式数据”。

## 正式版接入边界

原型确认后，正式版再增加本机设置字段和历史淘汰策略；本轮原型不触碰正式剪贴板数据，也不改变现有三种时间清理规则。
