# 花海剪贴板产品设计规格

状态：用户已确认产品、视觉、架构、数据流与验收范围  
日期：2026-08-04  
交付模式：`full-build`  
资源策略：`balanced`

## 1. 产品定义

花海剪贴板是一款面向 Windows 10 与 Windows 11 的本地桌面剪贴板历史工具。用户可通过全局鼠标中键、全局快捷键或屏幕边缘热区快速打开液态玻璃悬浮面板，查找最近复制的文本、链接、图片和文件路径，并重新复制或直接粘贴到原应用。

首版不要求注册账号，不上传剪贴板、设置、遥测或日志。数据按当前 Windows 用户隔离并保存在本机。

### 1.1 核心目标

- 从鼠标位置或屏幕边缘快速恢复最近复制内容。
- 在不阻塞系统剪贴板的前提下可靠采集、分类、去重和清理历史。
- 默认过滤密码管理器、浏览器无痕窗口、敏感内容和用户黑名单应用。
- 提供可关闭、可降级的液态玻璃、点击反馈和花瓣背景动效。
- 以标准 `.exe` 安装程序交付，并兼容 Windows 10 与 Windows 11。

### 1.2 非目标

- 首版不提供账号、云同步、跨设备剪贴板或团队共享。
- 首版不保存除文本、链接、图片和文件路径之外的任意私有剪贴板格式。
- 首版不内置自动更新器，不在用户未确认时上传诊断数据。
- 花瓣动效仅存在于花海剪贴板的窗口背景层，不覆盖整个 Windows 桌面。

## 2. 用户流程

### 2.1 鼠标位置临时面板

1. 用户单击鼠标中键。
2. 应用先记录当前前台窗口；若它不在中键排除列表中，临时面板出现在鼠标附近，并自动调整位置避免超出当前显示器工作区。只有面板成功唤出时才拦截本次中键事件。
3. 用户可搜索、筛选或用方向键选择历史记录。
4. 单击记录只恢复到系统剪贴板；双击或按 `Enter` 恢复内容、切回原窗口并粘贴。
5. 单击复制或自动粘贴成功后，临时面板自动隐藏；自动粘贴失败时仍保留内容在系统剪贴板，并提示手动按 `Ctrl+V`。

中键排除列表中的应用保留原始中键行为。全局快捷键和托盘入口始终作为备用入口。

### 2.2 屏幕边缘面板

- 默认停靠当前屏幕右侧，可拖到左侧。
- 每台显示器分别记忆停靠侧、纵向位置和 DPI 缩放。
- 鼠标靠近或点击边缘把手后展开，鼠标离开后收起。
- 展开面板与临时面板共享搜索、筛选、收藏、置顶、删除和粘贴行为。

### 2.3 设置与托盘

设置窗口可从系统托盘菜单或面板齿轮按钮进入。托盘菜单包含显示面板、暂停记录、隐私模式、清空历史、设置和退出。

设置分类：

- 外观：五套皮肤、自定义主色、透明度、模糊、反光、面板尺寸和紧凑模式。
- 动效：A+E 点击动效参数、花瓣飘落开关与强度、减少动态效果。
- 唤出方式：中键、全局快捷键、边缘热区和应用排除列表。
- 剪贴板：保留天数、最大记录数、图片大小限制和自动清理。
- 隐私：密码管理器、无痕窗口、应用黑名单、暂停记录和一键清空。
- 行为：单击复制、双击或 `Enter` 粘贴、操作后自动隐藏。
- 显示器：每台显示器的停靠侧、位置和缩放。
- 系统：开机启动、托盘运行、语言、设置备份与恢复。备份只包含非敏感设置，不包含剪贴板历史、缩略图或来源应用记录。

设置按当前 Windows 用户保存，修改皮肤和玻璃参数时实时预览并立即生效。

## 3. 信息架构与界面

历史记录顶部提供搜索框和类型筛选：全部、文本、链接、图片、文件、收藏。列表项包含类型图标、主要内容、来源时间、收藏/置顶状态和可用性状态。

记录支持：

- 单击复制；
- 双击或 `Enter` 自动粘贴；
- 收藏、置顶、删除；
- 文本、链接、图片和文件预览；
- 文件路径存在性提示；
- 键盘上下导航、`Esc` 关闭与焦点可见状态。

收藏和置顶记录不参与默认 7 天自动清理。取消收藏或置顶后，保留期从最后复制时间计算。连续复制相同内容只更新时间并移至顶部，不创建重复记录。

## 4. 品牌与视觉合同

### 4.1 品牌

- 产品显示名：`花海剪贴板`。
- 安装文件：`HuahaiClipboard-Setup.exe`。
- 应用本体：`HuahaiClipboard.exe`。
- 字标：A 款“花瓣流线”，花海两字使用玫瑰高光，剪贴板保持清晰楷意字形。
- 托盘图标：独立“花”字图形；托盘菜单标题使用纯文本“花海剪贴板”。
- 字标落位：悬浮面板左上角、设置窗口侧栏、安装程序和关于页。

### 4.2 液态玻璃

- 默认主题：玫瑰紫。
- 材质特征：桌面背景透视、紫色边缘折射、紫色流动光带、底部厚度与暗色内容透镜。
- 白色只用于主要文字和必要的可读性边界，不使用大面积白色反光。
- 五套内置皮肤：玫瑰紫、钴蓝、翡翠青、琥珀橙、极光青紫。
- Windows 11 使用完整合成效果；Windows 10 保持同一布局并降低模糊、饱和和折射复杂度。

### 4.3 动效

点击反馈采用 A+E 组合：

- 折射涟漪：从选择记录中心扩散主题色折射波。
- 磁吸浮起：记录和类型图标轻微上浮并弹性回落。
- 总时长约 `760ms`；减少动态效果模式下降级为 `120ms` 静态高亮。

花瓣采用 A 款“稀疏慢落”：

- 默认低强度，约 5 片小花瓣循环。
- 花瓣计算宽度约 `6-7px`，全部位于玻璃背景层。
- 内容层使用独立暗色透镜，花瓣不得出现在文字与记录卡片表面。
- 用户可设置关闭、低、中、高；省电模式、远程桌面或系统减少动态效果开启时自动停止。

### 4.4 可读性与可访问性

- 主要文字使用高对比纯白或近白色，次级文字保持稳定亮灰。
- 列表项和搜索框使用独立暗色半透明内容层。
- 所有核心行为支持键盘操作和可见焦点。
- 支持 Windows 高对比度、DPI 缩放和系统减少动态效果。
- 装饰动效不可接收点击、遮挡文字或改变布局尺寸。

## 5. 技术架构

技术栈：`.NET 8 + WinUI 3 + Windows App SDK + Win2D`。安装程序使用 Windows 桌面安装工具链输出标准 `.exe` 引导程序。

### 5.1 模块

- `ClipboardCaptureService`：监听系统剪贴板，在事件发生时快照前台进程与窗口身份，读取允许的格式并快速入队。
- `PrivacyFilter`：在持久化前检查来源应用、窗口模式、敏感内容与用户黑名单。
- `HistoryRepository`：管理 SQLite 元数据、加密负载、去重、搜索和清理。
- `GlobalInputService`：处理中键、全局快捷键、排除列表和钩子生命周期。
- `WindowManager`：管理临时面板、边缘面板、设置窗口、多显示器与 DPI。
- `VisualComposition`：管理主题令牌、液态玻璃、A+E 点击反馈和花瓣背景层。
- `TrayService`：管理托盘菜单、暂停、隐私模式和退出。
- `SettingsService`：保存每个 Windows 用户的设置并执行版本迁移。
- `InstallerIntegration`：安装、卸载、开始菜单和开机启动集成。

这些模块通过接口通信。剪贴板监听线程只负责读取和入队，不直接执行图片解码、数据库写入或 UI 更新。

## 6. 数据与隐私

### 6.1 数据模型

每条历史记录包含：

- 唯一 ID；
- 类型：文本、链接、图片或文件；
- 内容哈希与规范化哈希；
- 创建时间、最后复制时间和使用次数；
- 收藏、置顶和可用性状态；
- 加密负载位置与缩略图位置；
- 经最小化处理的来源应用标识。

SQLite 只保存必要元数据。文本、路径、图片和缩略图负载使用 Windows DPAPI `CurrentUser` 范围加密，数据库仅保存加密文件位置。搜索索引在应用运行期间从已解密的有限历史构建在内存中，退出后清除。

### 6.2 隐私优先级

隐私过滤发生在去重、缩略图处理和持久化之前。来源应用以剪贴板事件发生时的前台进程和窗口身份为准；该身份只在通过隐私过滤后做最小化保存。默认不记录：

- 已知密码管理器；
- 浏览器无痕或隐私窗口；
- 用户应用黑名单；
- 被敏感内容规则识别为密码、验证码或密钥的内容；
- 来源无法确认且具有高敏感特征的内容。

密码管理器和受支持浏览器的隐私窗口使用内置签名规则识别，用户黑名单按可执行文件身份匹配。识别结果不确定但内容具有高敏感特征时，按“不记录”处理。暂停记录和隐私模式立即停止新内容持久化。清空历史需要明确目标提示，并删除数据库记录、加密负载、缩略图和内存索引。

## 7. 数据流与失败处理

1. Windows 发出剪贴板变更事件。
2. `ClipboardCaptureService` 读取允许格式并放入有界后台队列。
3. `PrivacyFilter` 判断是否允许处理。
4. 后台管线执行规范化、去重、分类、图片缩略图和 DPAPI 加密。
5. `HistoryRepository` 写入数据，并向 UI 发布增量变更。
6. 用户恢复记录时，应用写回系统剪贴板；需要自动粘贴时恢复原窗口并发送粘贴命令。

失败规则：

- 数据库不可用时使用有上限的内存队列，恢复后重试，不阻塞系统剪贴板。
- 图片解码失败时不显示损坏缩略图，并保留可安全识别的元数据。
- 文件不存在时仍可复制原路径，但显示“文件不可用”。
- 自动粘贴失败时保留系统剪贴板内容并提示手动粘贴。
- 中键钩子异常时自动停用中键入口，保留快捷键和托盘入口。
- 数据损坏时隔离损坏记录，保留其余历史，并提供安全重建。
- 应用退出或崩溃时释放全局钩子和透明窗口，不留下明文临时文件。

## 8. 性能与兼容目标

- 面板热唤出目标：P95 小于 `100ms`。
- 剪贴板事件入队目标：P95 小于 `20ms`。
- 动画目标：支持 GPU 时保持 `60fps`，不得因花瓣或玻璃效果改变布局。
- 空闲内存目标：首版小于 `180MB`。
- 默认最多保留 7 天、1000 条非收藏记录；限制可在设置中调整。
- 单张图片默认上限 `20MB`，超过限制时不持久化并给出非侵入提示。
- 覆盖 Windows 10 22H2 与当前受支持的 Windows 11 版本。

## 9. 安装与更新

交付物：

- `HuahaiClipboard-Setup.exe`：安装、卸载、开始菜单入口，并在安装时由用户选择是否启用开机启动。
- `HuahaiClipboard.exe`：安装后的应用本体。

未签名构建可能触发 Windows SmartScreen 提示。正式公开发布前需要代码签名证书。首版通过用户主动下载安装包完成升级，不包含应用内更新下载或静默安装。

## 10. 测试与验收

### 10.1 自动化

- 隐私过滤、去重、保留期清理、收藏与置顶例外。
- DPAPI 加密/解密、损坏记录隔离和设置迁移。
- 中键排除规则、快捷键回退和多显示器位置计算。
- 文本、链接、图片和文件数据适配器。
- Windows 10 降级渲染参数与减少动态效果规则。

### 10.2 桌面集成

- Windows 10 与 Windows 11 各执行一轮真实复制、恢复和自动粘贴。
- 单屏、双屏、混合 DPI、左右停靠和鼠标边界位置。
- 托盘生命周期、开机启动、安装、升级和卸载。
- 密码管理器、浏览器无痕窗口、黑名单应用和暂停记录。
- 键盘导航、焦点、`Esc`、高对比度和中文长文本。

### 10.3 视觉与动效

- 玫瑰紫和另外四套皮肤的主要窗口与设置窗口。
- 默认、悬停、焦点、选中、禁用、空、错误和权限状态。
- A+E 初始/中间/结束关键帧和短录屏。
- 稀疏慢落花瓣的背景层级、计算尺寸、开关和降级模式。
- Windows 10/11 相同场景、相同数据和相同 DPI 的差异检查。

验收标准：核心复制流程不阻塞；受支持的密码管理器、浏览器隐私窗口和用户黑名单场景无已知误记录；设置重启后恢复；Windows 10/11 核心行为一致；任何 P0/P1 问题均阻止发布。
