# 花海剪贴板：面板隐藏按钮设计

## 用户目标

在主面板顶部工具栏、设置齿轮按钮旁增加一个明确的“缩小”按钮。用户单击后，面板立即隐藏到后台；程序不退出，剪贴板监听和历史记录继续工作。

## 交互设计

- 使用与设置按钮相同的圆形玻璃图标按钮样式，显示减号图标 `−`。
- 按钮位于搜索框之后、设置齿轮之前，提示文字为“隐藏到后台”。
- 鼠标单击与键盘激活均执行现有 WebView 桥接动作 `hide`。
- 隐藏后不显示额外确认动画，避免延迟；用户可通过右键双击、自定义快捷键或托盘图标再次唤出。
- 按钮属于交互控件区域，不触发面板长按拖动。

## 技术边界

- 复用现有 `hide` 桥接协议和原生窗口隐藏逻辑，不增加新的窗口状态、设置项、数据字段或持久化格式。
- 不改变已确认的面板布局、主题、玻璃透明度、剪贴板功能和退出行为。
- 网页原型环境中复用现有 `hidePanel()` 降级行为，确保按钮仍可交互演示。

## 验收

- 结构测试确认按钮存在、位置紧邻设置按钮且具有可访问名称。
- 行为测试确认按钮调用 `hidePanel()`，原生环境发送 `hide`。
- Node UI 合同测试、Core 测试、Release x64 构建和安装版启动验证通过。
