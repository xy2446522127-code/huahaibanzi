# 花海剪贴板 v1.1.11 完整性修复 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补齐历史上浮、条数清理、图片生命周期、交互细节和更新安全缺口，并发布 v1.1.11 单文件安装器。

**Architecture:** 让历史源继续拥有所有记录变更，图片存储只处理受安装目录约束的二进制文件；独立的轻量保留服务复用时间和条数规则。WebView 仍加载同一份正式 `product-shell.html`，更新仍以 GitHub Release 为唯一客户端发布源。

**Tech Stack:** .NET 8、WinUI 3、WebView2、原生 HTML/CSS/JavaScript、MSTest、Node test、PowerShell 安装器。

## Global Constraints

- Windows 10 19041+ 与 Windows 11 x64。
- 数据只保存在安装目录 `Data/<SID>`，不上传 Git。
- 安装位置可选并拒绝 C 盘。
- 保留已确认 WebView 液态玻璃 UI、五主题、花瓣、狐狸图标和方正仿宋记录字体。
- 用户自行更新；本任务不得覆盖安装或删除现有用户数据。
- 不增加第三方运行依赖。
